  Word-Level Encoding Example
═══════════════════════════════════════════════════════════════════════════════

Hardware:                Z3 Word-Level:                 Bit-Blasted (avoided):
────────────────────────────────────────────────────────────────────────────────
iCounter (2-bit reg)    let c = mk_const "c" 2         let c0 = mk_bool "c0"
                                                        let c1 = mk_bool "c1"

iCounter + 1            let one = mk_numeral "1" 2     let s0 = xor c0 true
                        let sum = mk_add c one         let carry = and c0 true
                                                        let s1 = xor (xor c1 false) carry
                                                        let overflow = ...
                                                        (6+ boolean operations)

iCounter == 3           let three = mk_numeral "3" 2   let b00 = xnor c0 true
                        let eq = mk_eq c three         let b01 = xnor c1 true
                        → 1-bit result                 let eq = and b00 b01
                                                        (4 boolean operations)

CE ? 0 : (counter+1)    let ce = mk_const "CE" 1       Complex nested boolean
                        let zero = mk_numeral "0" 2    formula with many gates
                        let sum = mk_add c one
                        let result = mk_ite ce zero sum
                        → Elegant!                     → Exponential blowup!

────────────────────────────────────────────────────────────────────────────────
Z3 Variables:           15 bitvectors                  50+ booleans
Solver Complexity:      Linear in bit-width            Exponential in bit-width
Typical Speedup:        Baseline                       10-100x slower
