# SystemVerilog Decompiler Test Suite

Comprehensive test suite for `sv_main_unified` covering all backends and features.

## Overview

The test suite validates:
- ✓ All 4 backends (standard, structural, yosys, hardcaml)
- ✓ Sequential and combinational logic
- ✓ Memory detection and inference
- ✓ Register inference reporting
- ✓ 4-state value sanitization
- ✓ Scan and file modes
- ✓ Error handling

## Test Structure

```
test/
├── run_tests.sh           # Main test runner
├── input/                 # Test input files (auto-generated)
├── expected/              # Expected outputs (optional)
├── output/                # Actual outputs
├── obj_dir/               # Verilator JSON files
└── README.md             # This file
```

## Running Tests

### Run All Tests
```bash
./test/run_tests.sh
```

### Run Specific Test Category
```bash
# Backend tests only
./test/run_tests.sh | grep "Backend Tests" -A 20

# Memory tests only
./test/run_tests.sh | grep "Memory Tests" -A 10
```

### Debug Failed Test
```bash
# Run with verbose output
SV_DEBUG=1 ./test/run_tests.sh

# Examine output
ls test/output/
cat test/output/counter_structural.sv
```

## Test Cases

### 1. Backend Compatibility Tests
Tests that all backends can process basic designs.

| Test | Backends | Description |
|------|----------|-------------|
| counter.sv | All 4 | Simple counter with reset |
| pipeline.sv | All 4 | Multi-stage pipeline |

**Expected**: All backends produce valid output

### 2. Register Inference Tests
Tests structural backend's register reporting.

| Test | Feature | Expected Output |
|------|---------|-----------------|
| pipeline.sv | Multiple registers | Reports 3 registers |
| mixed.sv | Sequential + combinational | Reports only sequential regs |

**Expected**: Synopsys DC-style inference reports

### 3. Memory Detection Tests
Tests memory primitive inference.

| Test | Memory Size | Expected Behavior |
|------|-------------|-------------------|
| small_memory.sv | 4×8-bit (32 bits) | Expanded to registers |
| large_memory.sv | 32×32-bit (1024 bits) | Memory primitive |

**Expected**:
- Small: Individual DFFs
- Large: memory_1w2r primitive instance

### 4. Combinational Logic Tests
Tests handling of pure combinational logic.

| Test | Feature | Backends |
|------|---------|----------|
| combinational.sv | Multiplexer | Standard, Yosys |

**Expected**: No register inference, clean combinational output

### 5. 4-State Value Tests
Tests sanitization of x/z values.

| Test | Feature | Expected |
|------|---------|----------|
| fourstate.sv | 32'bxxx...xxx | Sanitized to 32'h0 |

**Expected**: Clean synthesis, no parse errors

### 6. Scan Mode Tests
Tests batch processing of multiple files.

| Test | Mode | Verification |
|------|------|--------------|
| All files | Scan | No verification |
| All files | Scan | With Z3 verification |

**Expected**: Process all files, generate summary

## Adding New Tests

### 1. Create Input File
```bash
cat > test/input/mytest.sv << 'EOF'
module mytest (...);
  // Your test design
endmodule
EOF
```

### 2. Add Test Case
Edit `run_tests.sh`:
```bash
run_test "My test description" "backend" "$TEST_INPUT/mytest.sv" "pass"
```

### 3. Run Tests
```bash
./test/run_tests.sh
```

## Debugging Tests

### Enable Verbose Output
```bash
# Set environment variable
export SV_DEBUG=1
./test/run_tests.sh
```

### Examine Intermediate Files
```bash

cat test/obj_dir/Vcounter.tree.json | jq .

# Generated output

# Warnings
cat test/output/scan_structural/warnings.txt
```

### Run Single Backend
```bash
# Manual test
verilator --json-only test/input/counter.sv
_build/default/sv_main_unified.exe file structural \
    obj_dir/Vcounter.tree.json \
    /tmp/test_output.sv
```

## Known Issues

### Verilator Warnings
Some tests may produce Verilator warnings (width mismatches, etc.). These are expected and do not indicate test failure.

### Verification Timeout
Z3 verification may timeout on large designs (>5000 LOC). This is expected behavior.

### Memory Conflicts
Test designs with >2 read ports or >2 write ports will intentionally fail with error messages.

## Performance

Typical test suite execution time:
- **Without verification**: ~5-10 seconds
- **With verification**: ~30-60 seconds (Z3 SMT solving)

## Requirements

- Verilator (any version with --json-only support)
- OCaml 4.14+
- Dune build system
- Z3 SMT solver (optional, for verification tests)
- Bash (for test runner)
