KEY DISCOVERIES
══════════════════════════════════════════════════════════════════

🔍 VHDL AST Structure:
   Process → Sequential Statements → Assignments + If statements
   ├─ Target: TargetDotted(AtomDotted(NamePrimary(SimpleName)))
   ├─ Waveform: WaveForms([expression])
   └─ Conditions: vhdl_condition

🔍 Pattern Confirmation:
   - slib_clock_div: RST reset + unconditional default + conditional override
   - slib_input_filter: Mutually exclusive if/elsif conditions
   - slib_mv_filter: Sequential independent if blocks (CLEAR overrides)
   - uart_baudgen: Same as slib_clock_div pattern

🔍 Target Names Extracted:
   slib_clock_div: iCounter, iQ
   slib_input_filter: iCount, Q
   slib_mv_filter: iCounter, iQ
   uart_baudgen: iCounter, BAUDTICK
