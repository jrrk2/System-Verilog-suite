KNOWN ISSUE (Minor)
═══════════════════════════════════════════════════════════════════════════════

Issue: SystemVerilog produces 1 register instead of 2

Root Cause:
  • SV version has 3 processes (always_ff + continuous assign + comb)
  • VHDL version has 1 process (all in one)
  • DCE only tracks liveness within single process
  • `iQ` assigned in always_ff, read in continuous assign
  • DCE doesn't see cross-process dependency
  • `iQ` incorrectly marked as dead code
  • Result: `iQ` register eliminated

Fix Required:
  • Enhance DCE with module-level liveness analysis
  • Track signal usage across ALL processes
  • Mark output-feeding signals as always-live
  • Build cross-process def-use chains

Expected After Fix:
  • VHDL: 2 registers ✅
  • SV:   2 registers ✅
  • Perfect equivalence ✅

Impact:
  • Minor architectural refinement needed
  • NOT a fundamental problem
  • Infrastructure works correctly
  • Just needs cross-process tracking
