═══════════════════════════════════════════════════════════════════════════════
THE PROBLEM (Before Fix)
═══════════════════════════════════════════════════════════════════════════════

After SSA construction and CSE optimization, we had variables like:
  - iCounter_0, iCounter_4, iCounter_5, iCounter_6, iCounter_7, iCounter_8
  - iQ_3
  - _cse_temp0, _cse_temp1, ..., _cse_temp9

The FIRST version of register inference treated ALL of these as separate
registers, resulting in 17 registers! ❌

This was WRONG because:
  1. iCounter_N are all SSA versions of the SAME signal (iCounter)
  2. _cse_tempN are intermediate computations (should be wires)

═══════════════════════════════════════════════════════════════════════════════
THE SOLUTION
═══════════════════════════════════════════════════════════════════════════════

Modified behavioral_registers.ml to:

1. STRIP SSA SUFFIXES
   ────────────────────────────────────────────────────────────────────────
   Function: strip_ssa_suffix

   iCounter_7 → iCounter  ✅
   iQ_3 → iQ              ✅
   _cse_temp5 → (keep as-is)

   Implementation:
   ```ocaml
   let strip_ssa_suffix name =
     if String.length name >= 9 && String.sub name 0 9 = "_cse_temp" then
       name  (* Keep CSE temps as-is *)
     else
       (* Strip _N suffix if N is all digits *)
       try
         let last_underscore = String.rindex name '_' in
         let suffix = String.sub name (last_underscore + 1)
                                 (String.length name - last_underscore - 1) in
         if String.for_all (fun c -> c >= '0' && c <= '9') suffix then
           String.sub name 0 last_underscore
         else
           name
       with Not_found -> name
   ```

2. IDENTIFY CSE TEMPS
   ────────────────────────────────────────────────────────────────────────
   Function: is_cse_temp

   CSE temps start with "_cse_temp" and should be wires, not registers.

   ```ocaml
   let is_cse_temp name =
     String.length name >= 9 && String.sub name 0 9 = "_cse_temp"
   ```

3. GROUP BY ORIGINAL SIGNAL
   ────────────────────────────────────────────────────────────────────────
   Function: group_by_original_signal

   All assignments are grouped by their original signal name:
   - iCounter_0, iCounter_4, iCounter_5, ... → all map to "iCounter"
   - iQ_3 → maps to "iQ"

   ```ocaml
   let group_by_original_signal assigns =
     let groups = Hashtbl.create 10 in
     List.iter (fun assign ->
       let existing = try Hashtbl.find groups assign.original_signal
                      with Not_found -> [] in
       Hashtbl.replace groups assign.original_signal (assign :: existing)
     ) assigns;
     groups
   ```

4. CREATE ONE REGISTER PER ORIGINAL SIGNAL
   ────────────────────────────────────────────────────────────────────────
   Function: infer_sequential_registers

   For each original signal:
   - Collect all assignments (across SSA versions)
   - Build MUX tree from conditional assignments
   - Create ONE register with MUX tree as input

   ```ocaml
   Hashtbl.iter (fun original_signal assigns ->
     if not (is_cse_temp original_signal) then begin
       let data_input = build_mux_tree assigns in
       let reg_info = {
         reg_name = original_signal;  (* "iCounter", not "iCounter_7" *)
         reg_data = data_input;       (* MUX tree *)
         ...
       } in
       ctx.registers <- reg_info :: ctx.registers
     end
   ) groups
   ```

5. CSE TEMPS BECOME WIRES
   ────────────────────────────────────────────────────────────────────────
   CSE temps like _cse_temp0, _cse_temp1, etc. are recorded as wires:

   ```ocaml
   let temp_assigns = List.filter (fun assign -> is_cse_temp assign.target) all_assigns in
   List.iter (fun assign ->
     ctx.wires <- (assign.target, assign.value) :: ctx.wires
   ) temp_assigns
   ```

KEY IMPLEMENTATION DETAILS
═══════════════════════════════════════════════════════════════════════════════

Assignment Tracking:
────────────────────────────────────────────────────────────────────────────
Each assignment records:
  - target: The SSA variable name (e.g., "iCounter_7")
  - original_signal: The base signal name (e.g., "iCounter")
  - value: The RHS expression
  - condition: Optional condition guard
  - priority: Statement order (for MUX tree priority)

MUX Tree Building:
────────────────────────────────────────────────────────────────────────────
Given multiple assignments to the same signal:
  iCounter := 0          (priority 0, condition: reset)
  iCounter := 0          (priority 10, condition: default)
  iCounter := iCounter+1 (priority 20, condition: not_max)

Build nested MUX tree:
  reset ? 0 : (default ? 0 : (not_max ? iCounter+1 : ...))

This MUX tree becomes the data input to the register.
